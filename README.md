# BB Sidebar Search

Кнопка **Поиск тредов** вверху списка тредов, рядом с **New thread**, слева от стрелок **Go back / Go forward**.

![Кнопка поиска рядом с New thread](docs/screenshot.png)

Кнопка открывает штатный поиск BB с его фильтрами и результатами. Работает в обычных тредах, сабтредах и на странице New thread, включая мобильную боковую панель.

## Установка

```sh
bb plugin install https://github.com/artbear/bb-plugin-sidebar-search
```

Плагин работает во всех открытых окнах BB. Настройки и отдельная учётная запись не нужны. После подключения открытые окна получают кнопку автоматически.

## Требования и ограничения

- Версия плагина **0.1.2** требует **BB ≥0.47.1** и **Plugin SDK ≥0.6.79**. Проверено на BB **0.47.1** (SDK **0.6.79**) и **0.48.0** (SDK **0.6.94**).
- Поддерживается штатная навигация **Rail** (Settings → Appearance → Navigation).
- **Search threads должна быть включена на левой панели** (Customize rail → Search threads). Плагин добавляет кнопку и вызывает существующую кнопку поиска; если её скрыть, дополнительная кнопка также исчезнет.
- Доступ к заголовку боковой панели сделан через официальный `app.contentScripts.register`. Плагин находит его по атрибуту `data-sidebar-header-slot` внутри заголовка списка тредов. При изменении разметки BB может потребоваться обновление плагина. Новую навигацию плагин не регистрирует.
- Плагин не заменяет список тредов и не содержит собственного поискового движка. Горячие клавиши берутся из штатной кнопки, поэтому переназначение сочетания учитывается автоматически.

## Отключение

```sh
bb plugin disable sidebar-search
```

Кнопка, наблюдатель DOM и обработчики удаляются при отключении или перезагрузке плагина.

## Разработка и проверка

Для тестов требуется Node.js 24 или новее.

```sh
npm ci
npm test
npm run typecheck
bb plugin build
bb plugin install .
```

Тесты проверяют допуск BB 0.47.1 и 0.48.0 в требованиях совместимости, появление кнопки в новой разметке BB 0.47.1, вызов актуального действия BB, недоступность поиска, смену сочетания клавиш, перерисовку заголовка, несколько боковых панелей, отсутствие дубликатов, очистку и использование только публичных импортов SDK.

В живом BB проверены расположение кнопки, открытие поиска и нахождение треда, обычный тред и сабтред, New thread, перезагрузка, отключение и повторное включение плагина.

## Изменения 0.1.2

Убраны верхние границы версий BB и SDK, из-за которых BB 0.48.0 отказывался загружать плагин. Минимальные требования сохранены. SDK сборки обновлён до 0.6.94; добавлен тест совместимости манифеста с BB 0.48.0. Кнопка, поиск и жизненный цикл проверены в BB 0.48.0.

## Изменения 0.1.1

Исправлено исчезновение кнопки после обновления BB: в 0.47 заголовок стал частью Navigation, и его `data-testid` изменился с `nav-rail-header` на `sidebar-header-slot`. Теперь используется атрибут заголовка, не зависящий от этого тестового идентификатора. Обновлены SDK, lock-файл и требования совместимости.
